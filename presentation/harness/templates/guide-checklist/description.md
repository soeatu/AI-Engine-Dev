# Guide checklist

読者が次の行動へ進める状態かを、最大6項目のチェックで確認する締めスライドです。

## Layout

濃紺背景にカテゴリ、2行までの大見出し、2列3段のチェック項目を配置します。下部に参照リンクまたは次の行動を1行で示せます。各チェック記号と文言は個別に編集できます。

## When to use

- 章末または資料末尾で理解事項と完了条件を確認する場合。
- 読後に実行してほしい行動をチェック項目へ変換する場合。

## When not to use

- 項目に長い補足説明が必要な場合。手順または詳細ページへ分割します。
- Yes/No判定ではなく複数案の比較が目的の場合。比較レイアウトを使用します。

- `text-3`: 左上のチェック記号。
- `i-know-which-folder-owns-the-work`: 左上の確認項目。最大2行。
- `text-6`: 右上のチェック記号。
- `i-selected-only-the-skills-required-`: 右上の確認項目。最大2行。
- `text-9`: 左中央のチェック記号。
- `facts-assumptions-and-unresolved-ite`: 左中央の確認項目。最大2行。
- `text-12`: 右中央のチェック記号。
- `outputs-and-canonical-documents-agre`: 右中央の確認項目。最大2行。
- `text-15`: 左下のチェック記号。
- `completed-and-uncompleted-checks-are`: 左下の確認項目。最大2行。
- `text-18`: 右下のチェック記号。

- `reference-links-or-next-action`: 下部の参照リンクまたは次の行動。1行。
