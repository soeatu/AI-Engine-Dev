# Guide comparison

2つの領域、選択肢、または方式を同じ観点で比較し、下部に共通ルールを示すスライドです。

## Layout

左右対称の大型カードに分類、名称、最大5行の比較項目を配置します。下部のピル型要素には両者に共通する原則を1行で示します。左右は異なるアクセント色で識別します。

## When to use

- DevelopmentとPresentationの責務、入力、成果物、検証方法を比較する場合。
- 2案の違いだけでなく共通原則も伝える場合。

## When not to use

- 3案以上を比較する場合。表形式またはページ分割を使用します。
- 数値の精密比較が中心の場合。表またはグラフを使用します。

## Fields

- `comparison`: 上部のカテゴリラベル。
- `two-area-comparison`: 比較から読み取る結論タイトル。
- `left-area`: 左カードの分類ラベル。
- `development`: 左カードの対象名。
- `purposeprimary-inputstypical-skillsm`: 左カードの比較内容。最大5行。
- `right-area`: 右カードの分類ラベル。
- `presentation`: 右カードの対象名。
- `purposeprimary-inputstypical-skillsm-2`: 右カードの比較内容。最大5行。
- `shared-rule-evidence-canonical-sourc`: 下部に示す共通原則。1行。
- `ai-engine-dev-guide`: フッター左の資料名。
- `00`: フッター右のページ番号。
