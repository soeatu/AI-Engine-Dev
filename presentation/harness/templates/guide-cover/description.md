# Guide cover

説明書・導入ガイドの題名、対象、版または利用場面を最初に示す表紙です。

## Layout

濃紺背景と左端の青いアクセント帯で構成します。上からカテゴリ、1行の大見出し、最大2行の副題、版・利用場面を配置できます。ロゴを前提としない中立レイアウトです。

## When to use

- ワークスペースガイド、運用手順書、研修資料の表紙。
- 読者と到達点を副題で短く伝える場合。

## When not to use

- 長い概要や目次を同じページへ載せる場合。表紙の次に概要スライドを使用します。
- 会社指定のPowerPointマスターが必須の場合。承認済み原本から別テンプレートを取り込みます。

## Fields

- `guide-category`: 資料種別を示す短いカテゴリ。英数字換算で約25文字まで。
- `workspace-guide-title`: 表紙タイトル。1行を推奨し、長い場合は最大2行。
- `a-concise-subtitle-describing-the-au`: 対象読者と読後の到達点を示す副題。最大2行。
- `version-or-context`: 版、会議名、対象期間などの短い補足。
