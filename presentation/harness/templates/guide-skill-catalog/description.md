# Guide Skill catalog

最大4件のSkillまたはSkill分類を、利用場面と成果物まで含めて比較する一覧スライドです。

## Layout

上部にカテゴリと結論タイトル、下部に4列4行の表を配置します。列は分類、Skill、利用場面、主成果物です。各セルは短い句または1行を基本とし、情報量が多い場合は複数ページへ分けます。

## When to use

- Skillの選択肢を分類別に整理し、入口を比較する場合。
- 本文で主要Skillだけを示し、詳細一覧へつなぐ場合。

## When not to use

- 5件以上を小さな文字で詰め込む場合。同じレイアウトを複製します。
- 前提条件や例外を長文で説明する場合。個別の手順スライドを使用します。

## Fields

- `skill-catalog`: 上部のカテゴリラベル。
- `catalog-title-with-one-clear-takeawa`: 一覧から読み取るべき結論タイトル。
- `category`: 第1列の見出し。
- `skill`: 第2列の見出し。
- `use-when`: 第3列の見出し。
- `primary-output`: 第4列の見出し。
- `category-one`: 1行目の分類。
- `skill-name`: 1行目のSkill名。
- `when-this-skill-fits`: 1行目の利用場面。
- `primary-output-2`: 1行目の主成果物。
- `category-two`: 2行目の分類。
- `skill-name-2`: 2行目のSkill名。
- `when-this-skill-fits-2`: 2行目の利用場面。
- `primary-output-3`: 2行目の主成果物。
- `category-three`: 3行目の分類。
- `skill-name-3`: 3行目のSkill名。
- `when-this-skill-fits-3`: 3行目の利用場面。
- `primary-output-4`: 3行目の主成果物。
- `category-four`: 4行目の分類。
- `skill-name-4`: 4行目のSkill名。
- `when-this-skill-fits-4`: 4行目の利用場面。
- `primary-output-5`: 4行目の主成果物。
- `ai-engine-dev-guide`: フッター左の資料名。
- `00`: フッター右のページ番号。
