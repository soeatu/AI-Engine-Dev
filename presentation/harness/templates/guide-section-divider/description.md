# Guide section divider

章の切り替わりと、その章で読者が理解することを示す区切りスライドです。

## Layout

濃紺背景に大きな章番号、章タイトル、1行の学習到達点を縦に配置します。下部には細い区切り線と資料名を置きます。章タイトルは1行、説明は最大2行が目安です。

## When to use

- Development、Presentation、利用開始手順など、大きな章の開始時。
- 長い説明書で現在位置を明確にしたい場合。

## When not to use

- 小見出しごとに多用する場合。通常のコンテンツスライドを使用します。
- 章の説明に図表や複数項目が必要な場合。後続ページへ分割します。

## Fields

- `01`: 2桁を基本とする章番号。
- `section-title`: 章タイトル。1行を推奨。
- `what-the-reader-will-understand-in-t`: 章を読み終えたときの理解や行動。最大2行。
- `ai-engine-dev-guide`: 下部の資料名またはシリーズ名。
