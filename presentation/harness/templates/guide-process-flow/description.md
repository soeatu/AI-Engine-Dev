# Guide process flow

入力から引き継ぎまでの5段階を左から右へ示す標準ワークフロースライドです。

## Layout

上部にカテゴリと結論タイトル、中央に矢印で結んだ5枚のステップカードを配置します。各カードは番号、短い段階名、最大3行の説明を持ち、第2段階だけを強調表示できます。

## When to use

- 開発、資料作成、レビューなどの標準的な流れを5段階で示す場合。
- 各工程の順序と成果の受け渡しを強調する場合。

## When not to use

- 分岐や戻り線を含む複雑なフロー。ルーティングまたはArchitecture用レイアウトを使用します。
- 6段階以上の詳細手順。複数ページまたは手順レイアウトへ分割します。

## Fields

- `workflow`: 上部のカテゴリラベル。
- `five-stage-workflow`: フロー全体の結論タイトル。
- `01`: 第1段階の番号。
- `input`: 第1段階の短い名称。
- `goal-audience-evidence`: 第1段階の説明。最大3行。
- `02`: 第2段階の番号。
- `select`: 第2段階の短い名称。
- `folder-and-skill`: 第2段階の説明。最大3行。
- `03`: 第3段階の番号。
- `work`: 第3段階の短い名称。
- `artifact-and-source`: 第3段階の説明。最大3行。
- `04`: 第4段階の番号。
- `verify`: 第4段階の短い名称。
- `tests-and-visual-qa`: 第4段階の説明。最大3行。
- `05`: 第5段階の番号。
- `handoff`: 第5段階の短い名称。
- `results-and-risks`: 第5段階の説明。最大3行。
- `ai-engine-dev-guide`: フッター左の資料名。
- `00`: フッター右のページ番号。
