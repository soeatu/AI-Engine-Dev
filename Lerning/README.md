# AI-Engine-Dev 学習ガイド

このフォルダは、AI-Engine-Devで扱う「資料作成」と「システム開発」の全体像を、初めて参加する人が学ぶための入口です。

## 学ぶ順番

1. [資料作成の仕事](01_presentation.md)
2. [システム開発の仕事](02_system-development.md)
3. [AIを活用した共通ワークフロー](03_ai-assisted-workflow.md)

資料作成とシステム開発は別々の仕事に見えますが、どちらも「目的を確認する」「根拠を集める」「成果物を作る」「検証する」「次の人へ伝える」という共通の流れを持ちます。

## このリポジトリで目指す状態

- 初めて参加した人が、各フォルダの役割と作業の流れを説明できる。
- AIの回答をそのまま採用せず、根拠と実物を確認できる。
- 完成した成果物だけでなく、再利用できる手順、素材、テンプレート、検証方法も残せる。
- 実施済みの確認と未確認事項を分けて、次の担当者へ引き継げる。

## 用語

- `成果物`: スライド、設計書、ソースコード、テスト結果、調査報告など、作業の結果として利用されるもの。
- `根拠`: 仕様書、議事録、実装、ログ、テスト結果、公式文書など、判断を裏付ける情報。
- `完了条件`: 作業が終わったと判断するための、確認可能な条件。
- `未確認事項`: 必要だが、権限、環境、時間、情報不足などにより確認できていない事項。
